# Netflix Movie Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a Netflix movie dataset using Python and Pandas.

## 🎯 Objectives

- Analyze the most frequent movie genres
- Categorize movie ratings
- Find movies with the highest and lowest popularity
- Analyze movie releases by year
- Explore genre distribution and popularity

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Findings

- Drama is the most frequent genre in the dataset.
- Spider-Man: No Way Home has the highest popularity.
- 2020 has the highest number of filmed movies.

## 📁 Files

`Movie_Data_Analysis.ipynb` — Complete analysis, visualizations and conclusions.
